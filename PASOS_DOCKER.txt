INICIAR DOCKER (BACK + DB + FRONT)
  docker compose up --build -d

Ver estado de contenedores
- Comando:
  docker compose ps

Abrir frontend
- URL:
  http://localhost:4200

Apagar servicios (manteniendo datos)
- Comando:
  docker compose down

Apagar sin borrar contenedores (solo detener)
- Comando:
  docker compose stop
